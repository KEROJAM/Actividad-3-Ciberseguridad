3. Instalación según tu sistema

Investiga el procedimiento. Usa únicamente fuentes oficiales.

Docker Desktop y WSL2 (recomendado). Descarga los instaladores oficiales de Terraform y AWS CLI. Verifica desde PowerShell, Windows Terminal o WSL.
Docker Desktop (Intel o Apple Silicon). Usa brew (Homebrew) para Terraform y AWS CLI, o las descargas oficiales.
Ubuntu / Mint / Debian: APT para Docker Engine y Compose; repositorio oficial de HashiCorp para Terraform; AWS CLI por descarga oficial (curl/wget).
Investiga también: requisitos de virtualización, permisos y compatibilidad de tu equipo.

7. Criterios de seguridad

No publicar tokens.
No usar información confidencial real.
No apuntar los comandos a AWS de producción.
Si LocalStack acepta una solicitud anónima, trátalo como una limitación o comportamiento del simulador hasta contar con una validación independiente.
